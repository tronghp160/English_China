# Sổ Từ

Web app (PWA) ghi và ôn từ vựng tiếng Anh / tiếng Trung, dùng chung với bạn bè.

- Kế hoạch đầy đủ: [docs/PLAN.md](docs/PLAN.md)
- Hướng dẫn deploy: [docs/DEPLOY.md](docs/DEPLOY.md)

```bash
pnpm install
cp .env.example .env.local   # điền key Supabase, Anthropic, Pexels, Unsplash
pnpm dev
```
