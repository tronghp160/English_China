# Sổ Từ — vocabulary notebook (English / Chinese)

Full product spec and phased plan: [docs/PLAN.md](docs/PLAN.md). Work phase by phase (§14); commit after each phase.

## Stack
- Next.js 16 (App Router, Turbopack) + TypeScript strict, React 19. **`cacheComponents` is disabled on purpose** (almost every route reads the Supabase session cookie). `middleware` is now `proxy.ts` in Next 16.
- Tailwind CSS v4 (CSS-first config in `app/globals.css`) + shadcn/ui (`radix-nova`, components in `components/ui`, `cn` from `@/lib/utils`).
- Supabase (Postgres + Auth + Storage + RLS) via `@supabase/ssr`. Dev uses a **Supabase Cloud** project (no Docker on the dev machine); migrations in `supabase/migrations`, applied with `pnpm db:push`.
- AI: Vercel AI SDK (`ai` v7) + `@ai-sdk/anthropic`, zod schemas. Model from env `AI_MODEL`.
- SRS: `ts-fsrs`. Chinese: `pinyin-pro`, `hanzi-writer`, `opencc-js`.
- Tests: vitest (`tests/unit`), Playwright (`tests/e2e`).

Sample decks live in `lib/sample-data.ts` (also used by the in-app "Thêm bộ từ mẫu" button, `lib/actions/sample.ts`)

## Conventions
- UI text in Vietnamese; code, identifiers and comments in English.
- Mobile-first. Touch targets ≥ 44px, icon buttons need `aria-label`.
- Design system "Sáng Màu" (docs/redesign-v2/REDESIGN_V2.md, mockups in docs/redesign-v2/mockups; replaces "Vở mực tím"): bright, rounded, colored; tokens in `app/globals.css`. Neutrals `canvas` (page), `surface`, `surface-2`, `surface-3`, `fg`, `fg-muted`, `fg-subtle` (placeholders), `border`, `border-strong`; `primary` (ballpoint blue) with `primary-hover|press|soft|fg` and `on-primary`; semantic hues, each with `-soft` (pale background) and `-fg` (text on it): `en`, `zh`, `success`, `danger`, `due`, `streak`, `xp`; the palette `c-{blue,coral,mint,sun,grape,pink,orange,teal,red}` (+ `-soft`, `-fg`) for decks, modes and tiles (use `lib/tone.ts` `TONE_CLASSES`, never build class names at runtime); `rate-again|hard|good|easy` (+ `-press`) for rating buttons; `text-tone-1..5` for pinyin. Never raw hex in components; new text/background pairs go into `scripts/contrast.mjs` (AA check). Primitives: `Card` (default|soft|solid|outline, `interactive`), `IconTile`, `Button` (variants `pressable` = the CTA of a learning flow, `white` on the blue hero, `soft` with a `tone`; sizes up to `xl` 56px), `Badge` (`soft` + `tone`), `DeckArt` / `DeckArtBlock` / `DeckCard` + `lib/deck-colors.ts` (`deckColor(id)`), `WordHero` (word on a card with a language strip, pinyin per character), `Celebration` (ring/figure + Bin + confetti once), `ProgressRing`, `LangMark`, `EmptyState` + `FigureTile`, `SegmentedNav` / `SegmentedRadio`, `MODE_LOOK` (icon + hue per practice mode). Radius: `rounded-xs` 8, `sm` 10, `md` 14 (button, input), `lg` 20 (card), `xl` 28 (hero, flashcard, sheet), `full`. Shadows `shadow-xs|sm|md|lg|primary|hero`; dark mode uses a 1px border instead of relying on shadow. Fonts: Be Vietnam Pro only (`font-display` = 800, tight), `font-hanzi` / `font-hanzi-sans` = Noto Sans SC, `font-ipa`; numbers use `tabular-nums`. Motion: one moment per screen and only after a user action (flip, pop, confetti, sheet); no looping animation except Bin's blink and tail; all cut by `prefers-reduced-motion`. `/dev-ui` (development only) shows every primitive.
- Secrets only via env (`lib/env.ts` validates). Third-party APIs (AI, images) are called server-side only; `service_role` only in `server-only` modules.
- Language-specific behavior goes through `lib/lang/registry.ts`, not scattered `if (lang === "zh")`.
- Validate every Server Action / route input with zod.

## Layout
- `app/(marketing)`, `app/(auth)`, `app/(app)` route groups; API routes in `app/api`.
- `lib/supabase` (clients), `lib/ai`, `lib/images`, `lib/srs`, `lib/lang`, `lib/actions` (server actions).

## Deviations from the plan (keep this list updated)
- Design do/don't (REDESIGN_V2 §2) applies to every change. Do: color groups and distinguishes (each deck, mode and figure has a hue), soft block + same-hue strong text as the main color pattern, one solid hero per screen, soft layered shadows, big radii, big 800 numbers, lucide icons at stroke 2 inside colored tiles, a celebration at the end of a session. Don't: ruled lines, red margins, 田字格 cells (only the writing pad and stroke-order guides keep a dashed grid), paper texture, stamps, serif, purple-to-pink gradients, gradient text, blurred blobs, glassmorphism on cards (only the bottom nav and top bar blur), emoji in UI chrome (user-entered `word.emoji` is fine), raw hex in components, looping animation other than Bin.
- `words.created_by` is nullable (plan had `not null` + `on delete set null`, which conflict).
- `review_mode` enum also contains `cloze` (the plan lists cloze as a practice mode).

- **Dev pitfalls**: after editing `globals.css` the dev server may keep serving stale CSS: kill it, delete `.next/dev`, restart. A transform animation with a fill mode on a wrapper makes `position: fixed` children relative to it (the page-in animation has no fill). ## Admin (`/admin`, migration 000011)
- Who: `ADMIN_EMAILS` (comma separated, can only be changed in the env) or a row in `app_admins` (service role only, no client policies), granted in /admin → "Quản trị viên" or with `pnpm admin:grant <email>`. `lib/admin.ts` (`isAdmin`, `requireAdmin` → 404 for everyone else). The avatar menu shows "Quản trị" to admins.
- What: overview counts, users (search, lock/unlock via Supabase `ban_duration`, delete with Storage cleanup from `lib/account-files.ts`), public decks (hide = make private, delete), groups (delete), admins (grant by email, revoke). Reads in `lib/data/admin.ts` and actions in `lib/actions/admin.ts` use the service role, and every action re-checks the caller; nobody can act on their own account or on another admin (revoke first).
- A locked user keeps a valid session until the JWT expires (about an hour). E2E: `tests/e2e/admin.spec.ts`.
